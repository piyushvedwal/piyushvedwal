## 🚀 Featured projects

### 🎵 [Mini Shazam: Audio Fingerprinting from Scratch](https://github.com/piyushvedwal/audio-fingerprinting)
Identifies a song from a few seconds of (possibly noisy) audio using spectrogram peaks, hashed peak pairs and offset voting, with no ML libraries.
On the GTZAN dataset (999 tracks) it reaches **94–96% accuracy** on clean 3–10 s clips and **90%** on 10 s clips at 0 dB SNR.

`Python` `NumPy` `SciPy` `Streamlit` &nbsp;·&nbsp; **[▶ Live demo](https://audio-fingerprinting-uzv6d6h2pfjxyaqeciwpm2.streamlit.app)**

### 🔒 [Privacy-Preserving Synthetic Data Generator](https://github.com/piyushvedwal/Privacy-Preserving-Synthetic-Data-Generator)
Generates realistic synthetic tabular data with a formal **differential privacy** guarantee: a DP-GAN trained with DP-SGD via Opacus. Privacy is checked empirically with a membership inference attack on held-out rows and a distance-to-closest-record test, and results export as a report.
Built with [Ganesh Khetawat](https://github.com/gkganesh12).

`Python` `PyTorch` `Opacus` `CTGAN` `scikit-learn` `Streamlit` &nbsp;·&nbsp; **[▶ Live demo](https://piyush-synthetic-data-generator.streamlit.app/)**

### 🗓️ [SAMS: Student Attendance Management System](https://github.com/piyushvedwal/SAMS-Student-Attendance-Management-System)
A complete attendance platform built from my own software requirements specification. Admins, teachers, students and parents each get their own console: marking by roster or student check-in code, calendar history, CSV / Excel / PDF reports, and alerts for low attendance and unusual patterns such as possible proxy check-ins. Covered by 39 automated tests that run on every push.

`Python` `Streamlit` `SQLite` `pandas` `Altair` `pytest` &nbsp;·&nbsp; **[▶ Live demo](https://sams-piyush-vedwal.streamlit.app/)**

### 🌐 [Interactive Portfolio](https://github.com/piyushvedwal/piyush-portfolio)
Editorial-style personal site with a precision-reticle cursor, a dot-grid background that reacts to the cursor, and live canvas visuals for each project.
